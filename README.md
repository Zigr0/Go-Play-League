# Go-Play-League
A Windows popup that nags you to play League every 10 minutes. Both buttons say "Yes" only one of them means it.
go-play-league is a tiny Python reminder tool that pops up every 10 minutes with one message: "go play league." It gives you two buttons, both labeled "Yes" but only the right one actually launches the client. The left one is a decline wearing a disguise. It's smart enough to shut up if League's already running, so it won't nag you mid-game.
edit LEAGUE_PATH before running (default path is C:\Riot Games\Riot Client\RiotClientServices.exe)
